# Fiction Style Analysis

小説本文の収集・正規化・構造解析・意味抽出・文体計測・文体プロファイル化・自作品評価を扱う開発単位の設計ドキュメントです。

## ドキュメント構成

```text
docs/features/fiction-style-analysis/
├─ README.md
├─ basic-design.md
└─ detailed-design/
   └─ README.md
```

- `basic-design.md`: 本機能全体の基本設計。アーキテクチャ、責務分離、データモデル、パイプライン、実装フェーズの基準文書。
- `detailed-design/`: 基本設計を具体化する詳細設計。領域ごとに独立した文書を追加する。

## 設計方針

基本設計を上位仕様として扱い、詳細設計は基本設計の責務境界・データレイヤー・再解析可能性を維持したまま具体化します。

分析器、分類体系、Metric、LLMプロンプトなど変更頻度が高い要素は詳細設計側で管理し、基本設計には長期的に維持するアーキテクチャ原則を置きます。
